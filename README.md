# ⚡ Lightning Taskbar

替代 Windows 11 原生任务栏的液态玻璃任务栏，附带运行在**桌面壁纸层**的雷雨天气。

## 特性

- **液态玻璃**：系统级背景模糊 + 壁纸取色染色 + 顶部弧形高光 + 边缘折射亮边 + 缓慢流动的光泽带，胶囊形悬浮，宽 64px。
- **智能自动隐藏**：前台窗口挡到任务栏、最大化或全屏时滑出屏幕；鼠标碰到屏幕底边即弹出（全屏游戏/视频需停留 0.35 秒，防误触）；回到桌面或窗口不遮挡时自动显示。
- **桌面雷雨**：挂在 WorkerW 层（壁纸之上、桌面图标之下），不是覆盖在窗口上的透明层，不挡任何窗口、不拦截鼠标。包含多层景深雨丝、地面溅射、乌云压暗、分叉闪电与云层照亮、底部雨雾。桌面被最大化/全屏窗口挡住时自动暂停绘制。
- **联动**：闪电同时照亮任务栏玻璃；雷声按"光速 vs 声速"延迟，越亮越近、越响、带爆裂声；任务栏玻璃上有雨珠停留与滑落。
- **音效全程序化合成**：雨声（粉噪/白噪 + 随机雨滴）与雷声实时生成，无任何音频素材文件。

## 真玻璃与开始菜单

- **真玻璃**（`Glass/`）：任务栏和开始菜单实时截取背后（外扩 48px）的画面，用运行时编译的 HLSL 像素着色器（系统自带 `d3dcompiler_47.dll`）渲染：
  - `BackdropCapture`：原图 + 1/4 分辨率三遍盒式模糊（≈ 高斯）的磨砂图，背景不变时不重复上传；
  - `LiquidGlassEffect`：圆弧倒角折射 + 轻色散、磨砂本体、倒角吸收、1 像素宽且四周均匀的边缘高光线、外侧柔和投影；
  - `GlassDrops`：最多 16 颗雨珠，每颗都是真透镜（里面是背后景物的倒像），大的会滑落并留下小水点；
  - 浅色背景自动切换为“白磨砂玻璃 + 深色字”，深色背景为“清透玻璃 + 白字”。
  - 代价：玻璃窗口默认"不参与屏幕捕获"，**截图、录屏、会议共享屏幕时看不到它们**。需要时在"外观与通知设置"里打开"允许截图和录屏"，玻璃背景会定格、不再实时刷新。
  - 调试：存在 `%AppData%\LightningTaskbar\debug-show-in-capture` 文件时效果同上；创建 `debug-reload-settings` 文件会让程序重新读取外观设置并应用（读完自动删除）。
- **开始菜单**：单独按 Win 键或点闪电按钮打开。内容是全部应用（与系统开始菜单同源，含商店应用），支持搜索（回车启动第一项），底部有设置和电源。Win+E 等组合键不受影响，"Windows 开始菜单"按钮可打开原生菜单。
  - 右键应用：打开、以管理员身份运行、固定到“开始”/任务栏、打开文件位置、卸载（跳转到系统的已安装应用页面确认）。
  - Windows 只允许资源管理器修改系统开始菜单（第三方调用返回拒绝访问），所以“固定到开始”只作用于这个开始菜单，系统自己的布局不会被改动。
- **悬浮 Dock**（默认主题）：只放开始按钮和应用图标，底座近乎隐形，图标带倒影，鼠标靠近时放大。可停靠在底部、左侧或右侧。图标多到放不下时会自动变小。悬停特效可选：光遮罩（掠过图标的扫光 + 图标主色光晕）、光晕、聚光、弹跳或无。
- **Finder 栏**：Dock 主题下，托盘、输入法、天气、音效、快速设置、时钟和显示桌面在屏幕顶部的一条玻璃细栏里，可放左上角或右上角；窗口挡到它时自动收起，鼠标在顶边对应位置停留一下即呼出。
- **玻璃通知**：读取系统通知，在左上角（可改右上角）显示玻璃卡片，6 秒后收起，鼠标停留时不消失；点击卡片打开对应应用（系统接口不提供通知的原始动作，无法直接跳到具体消息）。免打扰和全屏时不弹出。
- 任务栏空白处右键 →“外观与通知设置…”：切换主题，调整 Dock 位置、悬停特效、图标大小、离边距离、放大倍率、倒影强度、玻璃浓度，以及 Finder 栏和通知的位置。
- **资源管理器玻璃**（默认关闭）：不注入 Explorer 只能改到标题栏，浅色主题下反差大。

## 使用

```
powershell -ExecutionPolicy Bypass -File build.ps1 -Run
```

（项目路径里的 `&` 和 emoji 会让 `dotnet build` 找不到 SDK，所以 `build.ps1` 把源码**单向复制**到 `%LOCALAPPDATA%\LightningTaskbar\src` 再编译，程序输出到 `%LOCALAPPDATA%\LightningTaskbarpp\LightningTaskbar.exe`。
旧版用的是 `%TEMP%` 里指向源码的目录联接，清理临时文件时会顺着联接把源码删掉——这很可能就是上次源码丢失的原因，现在已不再使用联接。崩溃原因会写入 `%AppData%\LightningTaskbar\error.log`。）

- 检测到动态壁纸（Wallpaper Engine 等）时，雨层自动切换为透明模式，雨下在动态壁纸之上。

- 左侧闪电按钮 = 开始菜单；中间是固定应用 + 运行中的应用。**同一应用的多个窗口合并成一个图标**（右上角显示窗口数）：左键切到最近用的窗口，再点轮换到下一个；右键菜单列出全部窗口，可“关闭全部”；中键关闭当前主窗口。
- **固定应用**：右键图标 →"固定到任务栏 / 从任务栏取消固定"；或把 `.exe` / `.lnk` 拖到任务栏上。首次运行会导入 Windows 任务栏上原有的固定项。运行中的程序会合并到对应固定图标上（能识别被迁移到其它盘、原位置只留链接的软件）。
- **系统托盘**：右侧常驻托盘图标，点 `^` 展开其余图标；左/右键、悬停都原样转发给应用，中键单击可在"常驻"和"收起"之间切换。首次运行沿用 Windows 设置里"在任务栏上显示"的图标。
- 右侧：天气切换（晴 → 雨 → 雷雨）、音效开关（滚轮调音量）、快速设置（Win+A）、时钟（Win+N）、显示桌面。
- 任务栏空白处右键：天气模式、手动打雷、任务管理器、**退出（恢复系统任务栏）**。
- 设置保存在 `%AppData%\LightningTaskbar\settings.json`。启动参数 `--rain` / `--storm` 可直接指定天气。

## 注意

- 若进程被强制结束，系统任务栏可能仍处于隐藏状态，运行 `restore-taskbar.ps1`（重启资源管理器）即可恢复。
- 当前版本只接管主显示器。
- 托盘基于 [ManagedShell](https://github.com/cairoshell/ManagedShell)（MIT），它会在本进程注册一个 `Shell_TrayWnd` 接收托盘消息，并同时转发给 Explorer。
- 桌面雨层按"填充"方式绘制壁纸，如壁纸使用"适应/平铺"可能有轻微差异。

## 环境要求

- Windows 11（Windows 10 2004 及以上也可，真玻璃需要 `WDA_EXCLUDEFROMCAPTURE`）
- [.NET 10 SDK](https://dotnet.microsoft.com/download)
